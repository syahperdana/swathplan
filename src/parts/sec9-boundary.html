Survey boundary import
Supported: SHP (+PRJ, or a ZIP), DXF, KML, KMZ, GPX, GeoJSON, WKT, CSV/TXT vertex lists. Select the .shp and .prj together.

CRS: KML, KMZ, GPX and GeoJSON are WGS84 by specification. SHP uses its .prj file when present. DXF, WKT and text lists carry no CRS, so they use the coordinate system in section {§crs}. DWG is a closed binary format and cannot be read in a browser: save it as DXF first (AutoCAD, BricsCAD, ODA File Converter or LibreDWG). If several shapes are found, the largest closed one becomes the boundary.
